# Iran RP Online — Starter

نمونه اولیه مستقل برای یک بازی نقش‌آفرینی آنلاین سبک SAMP.

## امکانات فعلی
- شهر آزمایشی
- بازیکن قابل حرکت با WASD
- دوربین دنبال‌کننده
- رابط فارسی
- چت محلی پایه

## معماری مرحله بعد
Android Client (Godot) -> Dedicated Game Server -> Database

پس از اضافه شدن سرور اختصاصی، حساب کاربری، چندبازیکنه، ماشین، شغل، پول، خانه و پلیس می‌توانند روی همین پایه توسعه داده شوند.

این پروژه از دارایی‌ها، نام‌ها یا کد اختصاصی GTA/SAMP استفاده نمی‌کند.
