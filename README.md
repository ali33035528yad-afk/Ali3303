# BeatNova

نسخه 1.1.0 تستی BeatNova برای پخش محتوای قانونی با Media3/ExoPlayer و Supabase.

## Build
Codemagic workflow در `codemagic.yaml` قرار دارد و خروجی APK در `app/build/outputs/apk/release/` تولید می‌شود.

## Supabase
جدول `songs` باید ستون‌های `id`, `title`, `artist`, `audio_url` و اختیاری `cover_url` داشته باشد.

فقط محتوای قانونی، دارای مجوز یا متعلق به خودتان را استفاده کنید.
